## 🚀 Cara Menjalankan & Membuka

### 1. Buka Langsung di Browser
Anda dapat langsung membuka file `index.html` atau halaman mana saja di browser:
```bash
google-chrome /home/muhammad-iqbal/projek/image_studio/index.html
```

### 2. Jalankan Server Web Lokal
```bash
cd /home/muhammad-iqbal/projek/image_studio
python3 -m http.server 8000
```
Lalu buka di browser:
👉 **`http://localhost:8000`**

Seluruh tombol, navbar, menu header, tombol hero, dan footer sekarang membuka halaman lokal yang sama persis.
